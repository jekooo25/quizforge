COMPACT QUIZ UI

Open Shared Quizzes. Each quiz title uses up to two lines with an ellipsis.
Tap its text area or Open quiz to see the full title, progress and review modes.
Select Quiz Battle or Word Bank, then press Start. Back returns to the library.
Join with code reveals Enter code. Browse public opens the public catalog.
Send saved results appears only when results are waiting to upload.
All UI controls are authored in editable Godot scenes.

Details scene: scenes/QuizDetails.tscn
Cards: scenes/quiz_card.tscn
Join controls: scenes/SharedQuizJoin.tscn
