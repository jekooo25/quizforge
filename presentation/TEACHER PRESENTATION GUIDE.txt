TEACHER PRESENTATION WALKTHROUGH

Start the sharing server, then reopen the Teacher and Student game windows.

1. TEACHER DASHBOARD
Review submissions: new quizzes awaiting approval.
Quiz library: approved, published and returned quizzes.
Published quizzes: active quizzes, join codes and student results.
Counts update when you open the dashboard or press Refresh.

2. REVIEW A STUDENT QUIZ
Open Review submissions. Use Search to find a title or creator.
Press Review quiz to read one question at a time with the correct answer,
explanation and source quote. Use Next question / Previous to navigate.
Approve quiz makes it ready for publishing. Request changes returns it.
Edit revision opens the existing private-revision editor.

3. PUBLISH
Open Library, then Publish quiz on the approved card.
Choose Private draft, Code-only or Public. The leaderboard is available
for Public quizzes. Press Save publication.

4. SHARE AND VIEW RESULTS
Open Published. Press Copy code and paste it into the Student join screen.
Student results opens reports for that exact quiz version.
Visibility changes who can find the quiz.
More contains Edit new revision and Close sharing when available.
Closing sharing prevents new joins and keeps existing reports.

5. DEMONSTRATE THE LEARNING LOOP
Have the student join and finish a Quiz Battle or Word Bank round.
In Teacher, open Student results and Refresh.
Show first-attempt accuracy, practice recall and remaining concepts.
If a result is missing, Student > Shared quizzes > Send saved results.
